# Literature Matrix

| Work | Venue/year | Central mechanism | Evidence | Relevance | Gap retained by this project |
|---|---|---|---|---|---|
| He, Treude, Lo, LLM-Based Multi-Agent Systems for Software Engineering | ACM TOSEM 2025 | Systematic review and research agenda | Literature review plus two framework case studies | Establishes SE multi-agent landscape | Does not operationalize handoff validity as an experiment outcome |
| Goal Drift in Language Model Agents | Technical report 2025 | Competing environmental objectives over long contexts | More than 100k-token settings | Direct construct for persistent objective adherence | Not repository-level recursive delegation |
| ReAcTree | arXiv 2025 | Hierarchical agent tree with control-flow and memory | WAH-NL and ALFRED | Closest recursive hierarchy | Embodied planning rather than Git state and merge authorization |
| MetaGPT | ICLR 2024 | SOP-encoded role workflows | Software-generation benchmarks | Structured roles and intermediate artifacts | No receipt-gated commit integration |
| ChatDev | ACL 2024 | Chat chain and communicative dehallucination | End-to-end software generation | Communication/handoff baseline | Natural-language handoffs are not bound to commit freshness |
| ReAct | ICLR 2023 | Interleaved reasoning and acting | QA and interactive environments | Single-agent trajectory baseline | No multi-agent authority model |
| Reflexion | NeurIPS 2023 | Verbal feedback stored in episodic memory | Coding and decision tasks | Retry/reflection baseline | Feedback is not deterministic proof of completion |
| SWE-agent | 2024 | Agent-computer interface for repository work | SWE-bench and HumanEvalFix | Repository execution baseline | Focuses interface design, not recursive handoff correctness |
| OpenHands | Open-source platform | General software-agent runtime | Repository tasks and community evaluation | Reusable sandbox/runtime ideas | Protocol must remain portable beyond one runtime |
| SWE-bench | ICLR 2024 | Issue-to-patch repository benchmark | Containerized tests on real GitHub issues | Public external task source and evaluator harness | Public exposure and test validity limit causal interpretation |
| OpenAI SWE-bench Verified audit | Technical audit 2026 | Contamination and task-level evaluator review | Memorization probes and manual audit | Establishes a current benchmark-validity threat | Not a peer-reviewed substitute for a controlled task set |
| OpenAI coding-evaluation audit | Technical audit 2026 | Audit of SWE-bench Pro task validity | Task/test inspection | Shows newer public suites also require task-level audit | Does not validate this project's controlled tasks |
